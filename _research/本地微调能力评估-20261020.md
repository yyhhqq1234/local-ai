## 0 结论先行（三句）

1. **硬件够格做 LoRA/QLoRA 级微调，但只到 8B–14B 量级；27B 在本机（12 GB VRAM）只能靠 CPU offload 硬撑，实用速度不具备。**

## 5 环境事实（影响可靠性的坑）

1. **工作区在百度网盘同步目录内**：`D:\BaiduNetdiskDownload\Local-AI`。实测多次出现同一路径"文件存在 → `Test-Path` False → `listdir` 空 → 递归又能列出"的间歇不可见（`runtime\python\python.exe`、`model\*.ninfer`、`工具\inspect_ninfer.py` 均复现）。判定为云盘占位符 / 按需下载行为。
   → **训练资产必须落在非同步盘（E:\ 或 G:\），否则 54 GB 权重落盘与读取会间歇失败。**
2. `游戏串流虚拟显示适配器`（GameViewer）在场，占位但 0 VRAM，不影响训练；但远程会话下 CUDA 长跑可能被会话策略影响，建议本地会话执行。

## 7 可行性结论

**分层结论：**

- **能做（改造成本低）**：8B 级 QLoRA 微调 + 导出 GGUF / 用 heretic 做定向行为改造。前提是先补 Python 3.12 + torch(cu12x, sm_120 wheel) + peft/bnb/trl。
- **勉强能做**：27B QLoRA（CPU offload），只适合"跑通流程 / 产几百条样本"，不适合规模化训练。
- **不能做**：对当前已部署的 `.ninfer` 就地微调；27B LoRA bf16 / 全参微调；纯 CPU 27B 训练。
- **关键卡口不是算力，是"没有全精度基座 + 没有训练环境"**。算力侧 12 GB 显存已到消费级中档，8B–14B 区间够用。

**要达到"给现有部署模型加/强化功能"的等价目标，最短路径是：**
```
① 装 Python 3.12 + uv（阿里镜像）
② 拉 Qwen3.5-27B（或 8B 替代）bf16 → 落 E:\ （非同步盘）
③ LoRA/QLoRA 微调（8B 本地 / 27B 租卡或 CPU offload 试验）
④ 合并 adapter → 转 GGUF → ninfer-v3 converter → 新 .ninfer 部署
```

### 9.5 27B 显存数学（按档精确）

| 方案 | 权重常驻 | 峰值估算 | 12 GB 卡判定 |
|---|---|---|---|
| QLoRA 4-bit NF4，27B | 27e9×0.5 B ≈ **13.5 GB** | 权重已超卡 | 必须 `device_map="auto"` 溢出到 CPU |
| LoRA bf16，27B | 27e9×2 B ≈ **54 GB** | 54 GB+ | ✗ |
| QLoRA 4-bit，14B | 14e9×0.5 B ≈ **7 GB** | ≈11–12 GB（2k ctx + 梯度检查点） | △ 贴边 |
| QLoRA 4-bit，8B | 8e9×0.5 B ≈ **4 GB** | ≈8–10 GB | ✓ 舒适 |

判据：**12 GB 卡舒适区 8B，14B 贴边，27B 必然 offload。**

### 9.6 落盘与吞吐预判

- 8B bf16 ≈ 16 GB，4-bit 缓存 ≈ 5 GB → E: 326 GB 充裕
- 27B bf16 ≈ 54 GB，转 GGUF Q4 再转 .ninfer 另需 15–20 GB
- 27B QLoRA offload：单步数十秒量级（流程验证可行，正式训练不可行）
- 8B QLoRA / 12 GB：bs1 × ga16 × 2k ctx，量级估计 1–3 s/step（非实测，落地后以真实 timings 为准）

|---|---|

### 10.2 三条路径的判定

| 路径 | 判定 | 依据 |
|---|---|---|
| **A. 原地微调 .ninfer** | ✗ 不能 | 引擎 `infer-serve.exe` 是推理专用二进制，无训练图 / 优化器 / 反传；容器是"索引 + 量化块"布局，不是可训练的计算图 |

### 11.4 对微调方案的三处实际影响

1. **基座下载目标改为 `Qwen/Qwen3.8-27B`**（约 27B 参数，bf16 ≈ 54 GiB；含 vision tower，比纯文本多约 0.6B）。
2. **transformers 必须 ≥5.8**，且要能识别 `Qwen3_5ForConditionalGeneration`；旧版会直接 `KeyError: Qwen3_5ForConditionalGeneration`。落环境前先跑：
   ```powershell
   & $py -c "import transformers;from transformers import AutoConfig;print(transformers.__version__);print(AutoConfig.from_pretrained(r'E:\LocalAI-train\base\Qwen3.8-27B').architectures)"
   # 期望 transformsers >= 5.8 且打印 ['Qwen3_5ForConditionalGeneration']
   ```
3. **要定微调模态**：只训 text decoder（推荐，LoRA 挂 `q/k/v/o`+`gate/up/down`，vision tower 冻结）还是 text+vision 联合。12 GB 卡上只有前者现实。
4. 额外注意：`linear_attention` 层的 `conv1d` / `a_log` / `dt_bias` 是 SSM 类参数，LoRA 不要覆盖它们（`target_modules` 只列 attention/mlp 的 Linear），否则会破坏状态空间动力学的数值稳定性。
