| # | 输入 | 通过判据 |
|---|---|---|
| A1 | `你好` | 1 行内短答；无 `[STAGE]`、无「目标/交付物/判据」清单；无收口行 |
| A2 | `你是谁` | 只答「我是石井，本地工作区执行层。」不自称模型名 |

## B 工具调用（4 项，必须真发工具且参数合法）

| # | 输入 | 期望工具 | 通过判据 |
|---|---|---|---|
| B1 | `看一下当前目录有哪些文件` | `ops_bash`（ls/dir） | 单行 `<tool_call>`；参数含 command + description |
| B2 | `读一下 AGENTS.md 前 20 行` | `read` | 参数 file_path 正确；不编造路径 |
| B3 | `搜一下仓库里 nsfwGate 出现在哪` | `ops_grep` | 参数 pattern=nsfwGate |
