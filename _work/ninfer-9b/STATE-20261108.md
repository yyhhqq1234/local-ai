## 已修复（均已提交入库）

1. **`c6faf4b` 采样空候选不再 trap**
   `src/ops/sampling/sample/kernel.cuh:56` → `red_val[0] = -CUDART_INF_F`；`:206` → `best = 0ull`。
   原来两处 `asm volatile("trap;")` 在 grammar mask 生效且归约值非有限时触发，
   表现为 `cudaErrorLaunchFailure` + 进程 `0xC0000409` 全灭（带 tools 的请求 100% 复现）。
2. **`8973a04` CUDA graph 打通（15.3 → 36.2 tok/s）**
   根因：9B MLP swiglu `src/ops/linear/swiglu/q4/shapes/n34816_k5120/dispatch.cpp:89,133`
   两处未关闭诊断块含 `cudaDeviceSynchronize`，捕获期 error 900 → 整个捕获 901 失效。
   配套：`src/core/decode_graph.{h,cpp}` 新增 `graph_capture_active()`（进程级 atomic）；
   `src/core/device.cu` 的 `DeviceContext::synchronize()` 捕获期直接 return
   （`stream_` 是 legacy 默认流，等价 `cudaDeviceSynchronize`）。
3. **`7e81e48` 数值正确性**
   `src/ops/linear/split/q4_q5/shapes/n5120_n5120_k4096/shape.cpp`：阈值 `<=12` → `<=15`，
   13–15 token 改走已验证的 4 段独立路径（原来走 `launch_matrix` 的 partial 分支时
   key/value 两个 1024 行段输出 NaN → norm_k → rope_k → KV cache → logits 全 NaN → HTTP 500）。

## ③ 的下一步（唯一未完成的可做项）

`selected token violates the request grammar` = grammar 掩码在首个采样步把所有候选置空。核对三处一致性：

```text
分配  program_impl.cpp:182-183   grammar_masks_device = plan.persistent.grammar_masks->bind(backing)
取址  grammar_masks.cpp:10-11,20-29   words = ne[0]；offset = row*(draft_window+1)*words；返回 {ptr, words}
消费  ops/sampling/kernels/distribution.cuh:178   words[overlay_len*stride + v/32] & (1<<(v%32))
```

必须成立：① `words*32 >= public_token_count`；② `mask.stride == words`；
③ `overlay_len` 落在 `fill_grammar_mask` 写入的 `(drafts+1)*words` 范围内。
任一不成立 → 读到未初始化词 → 整行全 0 → 全掩。
