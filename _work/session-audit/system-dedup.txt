## Windows Shell 规则（2026-09-26 已验证）

- 本机 PowerShell 7.6.6 与 5.1 相互独立共存。
- 7.x 全路径：C:\Program Files (x86)\PowerShell\7\pwsh.exe（FileVersion 7.6.6.500，PSEdition Core）。
- 5.1 路径：C:\windows\System32\WindowsPowerShell\v1.0\powershell.exe（5.1.22621.6060），不得用于 7.x 任务。
- PATH 内无 pwsh.exe，裸 pwsh.exe 会报 CommandNotFoundException，必须用全路径显式拉起。
- 所有 PowerShell 7 命令统一形式（单引号防外层 5.1 展开）：

 & 'C:\Program Files (x86)\PowerShell\7\pwsh.exe' -NoLogo -NoProfile -Command '<命令>'

- 第一次执行前先运行版本探活：

 & 'C:\Program Files (x86)\PowerShell\7\pwsh.exe' -NoLogo -NoProfile -Command '$PSVersionTable.PSVersion'

- 如果该全路径不可用，立即停止并提示告知，不要自动退回 Windows PowerShell 5.1。
