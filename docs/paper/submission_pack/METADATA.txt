[4. Abstract (Plain Text Format, Cleaned of LaTeX/Markdown for Web Forms)]
While Large Language Model (LLM) agents demonstrate remarkable general reasoning capabilities, deploying them to specialized, low-level system operating environments—such as binary reverse engineering, kernel debugging, dynamic memory forensics, and vulnerability triage—exposes acute contradictions between domain competence and behavioral controllability. In this paper, we conduct an extensive empirical and theoretical study on fine-tuning compact hybrid linear-attention agents (9B parameters) and dense full-attention agents (27B parameters) on native low-level system security tool environments. We uncover three pervasive failure modes that severely undermine autonomous cyber operations: (1) The Memorization Illusion: standard empirical cross-entropy loss reductions mask severe verbatim memorization (20-gram token overlap escalating from 0.167 to 0.515), where conventional held-out validation splits fail to detect brittle memorized tool mapping on binary inspection tasks; (2) Catastrophic Stage Overwriting: sequential multi-stage post-training completely overwrites preceding capabilities—dropping domain security tool calling accuracy from 82.5% to 10.0%—which we formalize through our Theorem on Low-Rank Subspace Interference Bounds and quantitative phase-transition collapse analysis; and (3) The Pareto Cliff of Subspace Abliteration: geometric weight-direction unlearning triggers an abrupt transition between complete refusal and severe linguistic collapse (KL divergence > 17) on compact models without achieving viable steering. Furthermore, we reveal a novel Spurious Gating Shortcut (an exploitable authorization bypass vulnerability resembling CWE-863), wherein condition-gated safety tuning inadvertently exploits response length disparities (1,065 tokens vs. 126 tokens) as an unintended authorization signal. To address these vulnerabilities, we propose DSDA (Decoupled System-Domain Adaptation), an integrated training and inference framework structured around three unifying pillars of decoupling: Semantic Decoupling via 4-axis query perturbation and candidate-aware tool clustering, Manifold Decoupling via runtime modular adapter routing (Scheme Z), and Causal Decoupling via counterfactual length-balanced paired gating formalized under Structural Causal Models (SCM) as an invariant reference monitor. Across comprehensive evaluations on 9B hybrid and 27B dense architectures over 5 random seeds, DSDA achieves an 82.5% +/- 1.4% tool generalization accuracy with zero hallucinations, statistically outperforming mainstream model merging baselines (Task Arithmetic 55.0%, TIES-Merging 62.5%, p < 0.01). Within our evaluated N=120 comprehensive adversarial test suite, DSDA achieves zero observed policy violations (GateLeak = 0.000), zero false refusals on technical traps (TrapRefusal = 0.000), and preserves 98.4% performance on cross-domain benchmarks.
