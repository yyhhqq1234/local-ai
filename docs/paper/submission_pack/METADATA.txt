Beyond Surface Adaptation: Deconstructing Memorization, Stage Overwriting, and Gating Biases in Domain-Specialized System Agents

[4. Abstract (Plain Text Format, Cleaned of LaTeX/Markdown for Web Forms)]
While Large Language Model (LLM) agents demonstrate remarkable general reasoning capabilities, deploying them to specialized, low-level system operating environments (e.g., kernel debugging, binary reverse engineering, and low-level system analysis) exposes acute contradictions between domain competence and behavioral controllability. In this paper, we conduct an extensive empirical and theoretical study on fine-tuning compact hybrid linear-attention agents (9B parameters) and dense full-attention agents (27B parameters) on low-level system tool environments. We uncover three pervasive failure modes: (1) The Memorization Illusion: standard empirical cross-entropy loss reductions mask severe verbatim memorization (20-gram token overlap escalating from 0.167 to 0.515), where conventional held-out validation splits fail to detect brittle memorized tool mapping; (2) Catastrophic Stage Overwriting: sequential multi-stage post-training completely overwrites preceding capabilities—dropping domain tool calling accuracy from 75.0% to 10.0%—which we formalize through our Theorem on Low-Rank Subspace Interference Bounds; and (3) The Pareto Cliff of Subspace Abliteration: geometric weight-direction unlearning triggers an abrupt transition between complete refusal and severe linguistic collapse (KL divergence > 17) on compact models without achieving viable steering. Furthermore, we reveal a novel Spurious Gating Shortcut, wherein condition-gated safety tuning inadvertently exploits response length disparities (1065 tokens vs. 126 tokens) as an unintended authorization signal. To address these vulnerabilities, we propose DSDA (Decoupled System-Domain Adaptation), an integrated training and inference framework comprising semantic query perturbation, candidate-aware hard-negative tool clustering, counterfactual length-balanced paired gating formalized via Structural Causal Models (SCM), and inference-time modular adapter routing. Evaluated on rigorous system workbenches across both 9B and 27B architectures, DSDA achieves an 82.5% tool generalization accuracy with zero hallucinations, outperforming mainstream model merging baselines (Task Arithmetic 55.0%, TIES-Merging 62.5%), while guaranteeing strictly zero security leakage (GateLeak = 0.0000), zero false refusals (TrapRefusal = 0.0000), and zero degradation of base capabilities.
